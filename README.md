IP Speed Test Android

一款基于 Kotlin 和 Go 的 Android IPv4 测速工具，支持批量 IP 导入、连通性检测、下载测速、国家代码识别及 GitHub 结果上传。

主要功能

- 多来源导入： 支持网络 URL、TXT 和 CSV 文件。
- IPv4 处理： 自动提取有效 IPv4 地址并去重。
- 连通性检测： 并发检测 HTTPS 连接，记录响应延迟。
- 下载测速： 对低延迟候选 IP 进行实际下载测试。
- 结果排序： 合格结果按下载速度从高到低排列。
- 速度过滤： 可设置最低显示速度，筛选需要查看的结果。
- 国家代码识别： 从来源数据中识别国家或地区代码，并显示在结果中。
- GitHub 上传： 支持将测速结果追加或覆盖写入指定仓库文件。
- 自动上传： 可配置测速完成后自动上传结果。
- 本地保存： 保存主要设置、导入数据及最近一次测速结果。
- 独立运行： 使用 Android 原生界面，无需另外安装 Termux 或 Root。

默认参数

参数| 默认值
连接检测并发数| 300
下载测速并发数| 100
低延迟候选数量| 20
最低显示速度| 0.5 MiB/s

速度单位为 MiB/s，最终结果按下载速度降序排列。实际测速表现会受到网络环境、服务器状态及并发设置影响。

使用方法

1. 配置网络 IP 来源，或导入 TXT/CSV 文件。
2. 根据需要调整测速参数和最低显示速度。
3. 开始测速，等待结果生成。
4. 查看并复制合格结果。
5. 如需上传，填写 GitHub Token、用户名、仓库名、分支及文件路径。
6. 选择追加或覆盖模式；也可以开启自动上传。

GitHub 上传提示： Token 需要具有目标仓库的相应写入权限。请勿公开分享访问令牌。

项目结构

- "MainActivity.kt"：Android 界面、参数设置、IP 导入、结果展示及 GitHub 上传。
- "myspeed.go"：核心连通性检测与下载测速逻辑。
- ".github/workflows/build-apk.yml"：GitHub Actions 自动构建配置。


注意事项

- 国家代码取决于来源数据，不保证地理位置绝对准确。
- 追加上传不保证自动去重。
- 上传内容以应用生成的测速结果格式为准，不应默认视为纯 IP 列表。
- 测速结果仅反映当前测试条件下的表现，不代表长期稳定速度。
