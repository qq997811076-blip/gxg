IP Speed Test Android

一款基于 Kotlin 和 Go 的 Android IPv4 测速工具，支持批量 IP 导入、连通性检测、下载测速、国家代码识别及 GitHub 结果上传。

主要功能

- 多来源导入： 支持网络 URL、TXT 和 CSV 文件。
- IPv4 处理： 自动提取有效 IPv4 地址并去重。
- 连通性检测： 并发检测 HTTPS 连接，记录响应延迟。
- 下载测速： 对低延迟候选 IP 进行实际下载测试。
- 结果排序： 合格结果按下载速度从高到低排列。
- 速度过滤： 可设置最低显示速度，筛选需要查看的结果。
- 国家代码识别： 从来源数据中识别国家或地区代码，并显示在结果中。
- GitHub 上传： 支持将测速结果追加或覆盖写入指定仓库文件。
- 自动上传： 可配置测速完成后自动上传结果。

GitHub 上传设置
Token： GitHub 访问令牌，需要具备目标仓库的写入权限。
用户名： GitHub 账号名称。
仓库名： 目标仓库名称。
分支： 例如 main。
文件路径： 例如 ip.txt。
上传模式： 追加或覆盖。
自动上传： 可选择在测速完成后自动上传结果。

注意事项

- 国家代码取决于来源数据，不保证地理位置绝对准确。
- 追加上传不保证自动去重。
- 上传内容以应用生成的测速结果格式为准，不应默认视为纯 IP 列表。
- 测速结果仅反映当前测试条件下的表现，不代表长期稳定速度。
