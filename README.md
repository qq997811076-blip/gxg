IPSpeed Android — IPv4 IP 测速工具

一款基于 Android 和 Go 测速核心的 IPv4 连通性检测与下载测速工具，支持多来源 IP 导入、并发测速、速度筛选、数据中心统计以及 GitHub 自动上传。

一、核心功能

- IPv4 连通性检测：对导入的 IPv4 地址进行连通性测试。
- 并发测速：支持独立设置连通性检测并发数和下载测速并发数。
- 低延迟 IP 优选：根据连通性检测结果，选择指定数量的低延迟 IP 进入下载测速阶段。
- 下载速度测试：通过可配置的 HTTPS 测速地址测试 IP 的下载速度。
- 合格结果筛选：按照最低显示速度筛选测速结果，并按速度从高到低展示。
- 数据中心汇总：提供数据中心统计汇总。
- 开始与停止：支持手动启动和停止测速任务。
- 实时状态显示：展示测速状态、导入数量和测速结果。

二、测速参数设置

- 连通性检测并发数可配置。
- 下载测速并发数可配置。
- 参与下载测速的低延迟 IP 数量可配置。
- 最低显示速度可配置，界面限制不低于 0.5 MiB/s。
- 支持设置下载数据量上限，可启用或关闭。
- 下载上限以 MiB 为单位，默认值为 1 MiB。
- 下载上限设置会应用于本次测速请求，不直接改写原始测速地址。
- 参数会自动保存，重新打开应用后可继续使用已保存的设置。

三、测速地址选择

内置多种测速地址选择方式：

- 自动选择：使用默认 Cloudflare 测速地址。
- Cloudflare：使用预设的 Cloudflare 测速地址。
- CM 提供：使用预设的 CM 测速地址。
- 移动专属：使用预设的移动网络测速地址。
- 手动输入：可以填写自定义 HTTPS 测速地址。
- 恢复默认：可以一键恢复自动选择模式。

四、IP 数据来源

支持本地 IP 数据与网络 URL 数据两种来源。

本地导入

- 支持选择 TXT 文件。
- 支持选择 CSV 文件。
- 支持从剪贴板导入 IP。
- 支持批量导入 IPv4 地址。
- 支持 IPv4 CIDR 网段展开。
- 自动识别和去除重复 IPv4 地址。
- 显示本次导入数量、重复数量、新增数量及累计保存的唯一 IPv4 数量。
- 支持清除已导入的本地 IP。
- 可以单独启用或关闭本地 IP 来源。

网络 URL 来源

- 支持配置多个网络 URL，每行一个。
- 支持添加、编辑和删除 URL。
- 内置默认 IP 数据源。
- 支持独立启用或关闭网络 URL 来源。
- URL 编辑和来源设置会自动保存。

默认网络 URL：

- "https://zip.cm.edu.kg/all.txt"
- "https://countrymerge.pages.dev/all.txt"

五、地理信息来源

地理信息由 Cloudflare HTTPS Trace 响应和数据中心位置映射数据提供。

- 数据中心代码（colo）：从 Cloudflare Trace 响应中获取。
- 国家／地区代码（loc）：从 Cloudflare Trace 响应中获取。
- 国家、区域和城市信息：通过本地 "locations.json" 或网络位置映射数据进行匹配。
- IP 来源：TXT、CSV、剪贴板和网络 URL 主要用于导入待测速 IP，不是地理信息的来源。

六、GitHub 上传

支持将测速结果直接上传到指定 GitHub 仓库。

- 自定义 GitHub 用户名。
- 自定义仓库名称。
- 自定义分支。
- 自定义上传文件路径。
- 支持覆盖上传。
- 支持追加上传。
- 支持手动立即上传。
- 支持测速完成后自动上传。
- 支持测试上传。
- 显示上传连接状态。
- 显示最后上传时间和上传数量。
- 自动保存 GitHub 连接设置。
- GitHub Token 使用 Android Keystore 加密保存。

使用前需要配置具有目标仓库相应文件写入权限的 GitHub Token，并选择覆盖上传或追加上传模式。

七、数据保存

- 自动保存测速参数。
- 自动保存测速地址选择。
- 自动保存 IP 来源设置。
- 保存已导入的唯一 IPv4 地址。
- 保存与 IP 对应的地理信息元数据。
- 保存 GitHub 上传配置和上传状态。
- 重新打开应用后可以恢复已保存的数据和设置。

八、使用流程

1. 导入 TXT/CSV 文件、从剪贴板导入 IP，或启用网络 URL 来源。
2. 选择测速地址。
3. 设置连通性并发数、下载测速并发数及低延迟 IP 数量。
4. 根据需要设置最低显示速度和下载上限。
5. 点击「开始测速」。
6. 查看合格结果、速度排序及数据中心汇总。
7. 点击「复制当前结果」复制符合当前速度筛选条件的结果。
8. 根据需要手动上传结果，或启用自动上传至 GitHub。

九、技术说明

- Android 原生界面。
- Go 测速核心。
- 通过 Android 原生网络栈读取 IP 来源。
- 支持并发检测和下载测速。
- 支持本地持久化设置。
- 支持通过 GitHub API 上传测速结果。
