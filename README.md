# IP Speed Test Android

一款基于 Termux 核心测速逻辑开发的 Android IP 批量测速与优选工具。

本软件将原本运行在 Termux 环境中的测速程序封装为独立 Android APK，无需安装 Termux，无需 Root，无需额外配置 Linux 环境，安装后即可直接使用。

软件主要用于：
- Cloudflare IP 优选
- CDN 节点测速
- 代理节点出口 IP 筛选
- 大批量 IPv4 地址速度测试
- 优质 IP 筛选保存


==============================
功能介绍
==============================


【1. 批量 IP 测速】

支持大量 IPv4 地址批量测试。

功能包括：

- IPv4 连通性检测
- TCP/HTTPS连接测试
- 下载速度测试
- 多线程并发测速
- 自动统计测速结果
- 按速度排序显示

支持自定义：

- 测速地址
- 测试时间
- 并发数量


==============================
【2. IP 地址管理】
==============================

支持：

- 手动编辑 IP 列表
- 从剪贴板导入 IP
- 剪贴板追加 IP
- 剪贴板覆盖 IP
- 自动过滤无效内容
- 自动去除重复 IP


IP 导入规则：

每行读取一个地址。

处理规则：

1. 自动忽略开头空格
2. 必须以 IPv4 地址开头
3. IPv4 后面的内容自动忽略
4. 非 IPv4 内容自动丢弃
5. 重复 IPv4 自动去重


例如输入：

1.1.1.1
8.8.8.8:443
9.9.9.9#test
abc123
2001:db8::1


最终保存：

1.1.1.1
8.8.8.8
9.9.9.9


只测试有效 IPv4。


==============================
【3. 实时测速显示】
==============================

测速过程中：

- 实时显示测试进度
- 实时显示测速结果
- 显示当前最快 IP

测试完成：

- 显示全部测速结果
- 自动排序
- 支持速度筛选


支持设置最低显示速度：

例如：

0.5M

低于该速度的结果不会显示。

注意：

过滤只影响显示，
不会删除测速数据。


==============================
【4. 历史记录】
==============================

支持保存历史测速结果。

包括：

- IP地址
- 测速速度
- 测试时间
- 测试参数

方便查看以前测试结果。


==============================
【5. GitHub 自动同步】
==============================

支持将测速结果上传到 GitHub。

提供两种模式：


追加模式：

- 保留原文件内容
- 将新的测速结果添加到文件末尾


覆盖模式：

- 删除原文件内容
- 使用当前结果重新生成文件


支持保存：

ip.txt


方便用于：

- Cloudflare IP列表维护
- 代理配置更新
- 自动化节点筛选


==============================
【6. 数据自动保存】
==============================

软件会自动保存用户设置。


保存内容包括：

- 测速 URL
- 测试时间
- 并发数量
- IP列表
- 历史结果
- 软件配置


关闭软件后：

重新打开即可恢复之前状态。


==============================
【7. 软件特点】
==============================

特点：

- Android 原生 APK
- 无需 Termux
- 无需 Root
- 内置测速环境
- 支持大量 IP 测试
- 支持高并发测速
- 支持 IPv4 自动解析

- 支持长期使用


==============================
【使用方法】
==============================


第一步：

导入或编辑 IP 列表。


第二步：

设置：

- 测速地址
- 测试时间
- 并发数量


第三步：

点击开始测速。


第四步：

等待测试完成。


第五步：

查看排序后的优质 IP。


第六步：

可以：

- 保存历史记录
- 上传 GitHub
- 用于代理配置


==============================
【适用场景】
==============================

适用于：

- Cloudflare IP 优选
- CDN 加速测试
- VPS 节点筛选
- 代理出口检测
- 网络质量测试
- IPv4 地址性能比较


==============================
【注意事项】
==============================

1. 测速结果会受到当前网络环境影响。

2. 不同地区、运营商测试结果可能不同。

3. 并发数量过高可能影响手机性能。

4. 建议根据网络情况调整测试参数。

5. 测试大量 IP 时建议使用稳定网络。
